# 읽기 전용 구조 점검 도구

`scripts/wiki_health.py`는 이 스킬을 위해 새로 작성한 Python 3.10 이상 표준 라이브러리 스크립트다. 외부 구현의 프로그램을 설치하거나 실행하지 않는다. 문서를 수정하지 않고 정합성과 재검토 후보를 보고한다. 기본 `python`이 실행되지 않으면 사용 가능한 Python 또는 Codex의 번들 런타임 경로를 확인해 사용한다.

## 실행

통합·이동·결정 교체를 완료로 보고하기 전에 실행하고 오류·경고를 검토한다. 실행할 수 없으면 지원 관계 종류와 출처/문서별 처리 기록을 포함한 같은 범위를 수동 점검하고 자동 검사 미수행을 보고한다.

실제 스킬 폴더의 절대 경로를 사용해 실행한다. 날짜는 사용자의 현재 날짜를 전달한다.

```text
python <skill-folder>/scripts/wiki_health.py --docs <project>/docs --as-of YYYY-MM-DD --json
```

종료 코드는 0이면 구조 오류 없음, 1이면 실행·입력 오류, 2이면 발견된 구조 오류가 있음이다. 경고만 있으면 0이며 경고 검토가 끝났다는 뜻은 아니다.

## 확인 범위

- 중복 문서 ID, 잘못된 생애 상태, 내용 없는 문서와 이전 스키마 징후.
- 로컬 Markdown·위키 링크의 대상 파일, 문서 ID 관계의 대상, 색인에서 찾을 수 없는 문서.
- 원자료 장부·주장 장부·처리 상태의 스키마와 참조.
- 보존본 SHA-256 불일치, 대응되는 현재 입력의 변경·누락, 재확인 시점 도래.
- 변경된 출처를 사용하는 현행 문서와 선언된 의존 관계의 후속 문서.
- 중요한 확인 주장에 근거·실제 확인일·확인 방법이 기록됐는지.

코드 블록의 예제 경로는 링크로 검사하지 않는다. `.wiki/`·`raw/`의 Markdown을 현행 지식 페이지로 검사하지 않는다. 레거시는 구조·링크·ID를 확인하되 현행 문서의 최신성 결과와 분리한다.

필수 머리말의 단일 값과 선택 목록의 한 줄 JSON 형식을 지원한다. 더 복잡한 기존 YAML 목록은 경고로 보고하므로 원래 문서를 일괄 변환하지 말고 필요한 범위에서 확인한다. URL 접속, Markdown 앵커, 문장의 의미, 원문 수치와 계산의 일치, 사용자 승인 여부는 자동 검증하지 않는다. 고립 문서의 유용성과 폴더 역할 중복은 별도 의미 검토로 확인한다.

해시 변화는 재검토 신호이며 잘못된 주장이라는 판정은 아니다. 검사를 통과했다는 이유로 `.wiki/state.json`의 처리 해시나 주장의 검토 결과를 갱신하지 않는다.

## 의미 있는 동작 검증

포함된 `scripts/test_wiki_health.py`는 사용자가 지정한 작업 폴더 안의 격리 자료를 이용한다. 실제 프로젝트를 수정하지 않는다.

```text
python <skill-folder>/scripts/test_wiki_health.py --workspace <scratch-folder>
```

정상 문서 연결, 중복 ID, 끊어진 링크, 보존 원자료 변조, 현재 입력 변경과 의존 문서 영향, 레거시와 현행 분리, 처리 버전 불일치, 순환 요약의 확인 주장, 복잡한 기존 메타데이터 경고, 검사 중 무변경을 확인한다.
